# Layout system

One grid so the ten read as a campaign rather than ten separate ideas.

## Formats

| Set | Ratio generated | Delivery | Inventory |
|---|---|---|---|
| Billboards B1 to B5 | **21:9** (widest Gemini supports) | extend to 3:1 for unipole, crop to 2:1 for 48 sheet | Sheikh Zayed unipole, bridge banner, mall gantry |
| Verticals V1 to V5 | **9:16** | 1080 x 1920 | Mall portrait, metro panel, Elevision lift screen |

Gemini 3 Pro Image supports 21:9 as its widest ratio. Dubai unipoles run wider still, so the billboard set is generated at 21:9 with the composition held clear of the far edges, leaving room to extend rather than crop into the subject.

## The grid

**Landscape.** Message occupies the **left third**. Visual occupies the right two thirds. This is the layout the OOH study set out to test and the one the collected evidence supports. Safe margin 6% of height on all sides. The tagline sits bottom left beneath the headline, at roughly a quarter of its size. Logo bottom right.

**Vertical.** Message occupies the **top third**, visual the lower two thirds, except V3 where the score is the hero and the message sits beneath it. Safe margin 8% of width. Tagline and logo stack at the base.

## Art direction, from the campaign visual grammar

Non negotiable, taken verbatim in spirit from the Reel and Story direction:

- **Morning light.** Warm, soft, never harsh.
- **Single focal action.** No busy compositions.
- **Soft system feedback.** No aggressive UI flourish. Subtle, calm.
- **Optimistic posture.** The user is more confident, not transformed.

This rules out the maximalist version of every direction. The container is not overflowing. The gestalt is not frantic. Restraint over flourish, in the campaign's own words.

**Key Visual versus Lived Imagery: never mix image types within a campaign moment.** The five billboards are one moment and hold one treatment. The five verticals are a second moment and hold another.

## Type

Pura typography is still marked Pending in the brand brain, and the brand book PDF is too large to extract. **There is no documented Pura typeface**, so no type specimen can be honoured here. The renders use a clean geometric sans as a stand in. Final artwork must be reset by the design team in the real face once it is defined. This is a known gap, recorded rather than papered over.

## Copy lockup

Every asset resolves on the locked tagline, which the brand system calls the period at the end of the sentence:

> **Pura knows your body like you do.**

Order: headline, then support line where used, then tagline, then logo. The tagline is never altered.

## Arabic

**No Arabic is generated by AI.** Model rendered Arabic script is unreliable and the RTL mirror changes the layout rather than translating it: in the Arabic executions the message moves to the right and the visual to the left, per the mirrored layouts found in the OOH study. AR versions are a compositing job for the design team, flagged not attempted.
